# EduAdmin - MTs Meunafa

Aplikasi Sistem Informasi Manajemen Sekolah (EduAdmin) untuk MTs Meunafa.

## Fitur Utama
- **Dashboard Ringkasan:** Statistik Siswa, Guru, Kelas Active, dan Modul Ajar.
- **Visualisasi Data:** Grafik Rasio Gender Siswa dan Statistik Usia Guru.
- **Akses Cepat:** Perangkat Ajar, Media Pembelajaran, LKPD Interaktif, dan Asesmen.
- **Status Penyimpanan:** Offline Ready (Penyimpanan Lokal).
